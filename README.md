# Food Delivery Sales Dashboard

## Project Overview

This project presents an interactive Power BI dashboard for analyzing food delivery sales data.

## Objectives

- Analyze total revenue
- Analyze total orders
- Analyze average order value
- Analyze customer ratings
- Compare revenue across food categories
- Analyze orders across cities
- Compare delivery and takeaway orders
- Analyze revenue by payment method
- Analyze revenue trends over time
- Identify food items generating higher revenue

## Dashboard Features

- Total Revenue
- Total Orders
- Average Order Value
- Average Rating
- Revenue by Food Category
- Orders by City
- Revenue by Order Type
- Average Rating by Food Category
- Revenue by Order Date
- Revenue by Payment Method
- Orders by Food Category
- Revenue by Food Item

## Tools Used

- Microsoft Power BI
- Microsoft Excel
- GitHub

## Dataset

The dataset contains information about food orders, customers, food categories, prices, quantities, ratings, cities, payment methods and order dates.
